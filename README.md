# traP 講習会デモ

講習会の準備を楽にし、その過程で集まった情報を次の受講者・開催者へ残すための体験デモです。

## 起動

```bash
npm ci
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## デモで確認できる体験

- 過去資料・動画の有無で講習会を探す
- 年度ごとに独立した講習会と、その引き継ぎ関係をたどる
- 過去の講習会から新年度版を作る
- 開催構成・参加方法・資料・告知文を順に整える
- 受講完了を記録し、バッジを確認・共有する

データと変更内容はブラウザ内だけに保存されます。traQ・knoQ・Wikiへの書き込みは行いません。

# LeQtures — traP 講習会デモ

LeQturesは、講習会の準備を楽にし、その過程で集まった情報を次の受講者・開催者へ残すためのサービスです。このリポジトリでは、その中心体験をデモとして確認できます。

現在は仮の「Q」ロゴを使用しています。

## 起動

```bash
npm ci
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## デモで確認できる体験

- 過去資料・動画の有無で講習会を探す
- 年度ごとに独立した講習会と、その引き継ぎ関係をたどる
- 過去の講習会から新年度版を作る
- 開催枠・場所・資料・告知文を順に整える
- 受講完了を記録し、バッジを確認・共有する

データと変更内容はブラウザ内だけに保存されます。traQ・knoQ・Wikiへの書き込みは行いません。

過去の講習会調査から、2016〜2026年度の356件、開催枠642件、公開可能な資料・動画など1,043件、情報源1,713件をデモへ取り込んでいます。調査で確認できなかった値は推測で補わず、「未確認」として扱います。

調査データを更新した場合は、検証済みのJSONLから画面用データを再生成します。

```bash
npm run import:research
```

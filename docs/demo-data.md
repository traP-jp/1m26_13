# ローカル表示確認用データ

`scripts/seed-research-demo.py` は、調査済みの `workshop-research/data/workshops.jsonl` から50件を選び、現在のLecture・Session・Flow形式へ変換する。

元のカタログは内部調査データのため、この公開リポジトリには含めない。実行には、アクセス権のある環境で用意したカタログを上記パスに配置する必要がある。カタログ・調査資料・ZIPはGitの追跡対象から除外している。

```sh
python3 scripts/seed-research-demo.py          # 変換内容の確認
python3 scripts/seed-research-demo.py --apply  # このcheckoutのcompose MariaDBへ追加
```

- 主催班が明示された37件と、残りから新しい年度順の13件を採用。
- 50講習会・140開催回。既存の講習会や完了記録を変更せず、同じ元データは再実行しても追加しない。
- 各班1件、合計7件は「開催予定テスト」として実行日の翌々日以降へ日程をずらす。タイトルと本文に架空の日程であることを表示。元の年度・日程も本文に残す。
- 資料・録画・リポジトリをリンクへ変換。開催回に対応する資料はその開催回に、それ以外は講習会に配置。
- 開催回が未登録なら日程未定の1回を用意。簡易変換のため各開催回は通常開催として公開し、再放送関係・年度間関係は新たに推定しない。
- 全件を運営画面で開けるよう、講習会の前後と各開催回にテスト用Flowを付ける。
- traQグループIDが未収録の班にはローカルテスト専用IDを使用。これは正式なインポートではない。
- 元の調査ファイルと本番DBは変更しない。変換内容はOSの一時ディレクトリ（Pythonの `tempfile.gettempdir()`）内の `leqtures-demo-import.json` にUTF-8で保存し、実際のパスを実行結果の `outputPath` に表示する。

通常のアプリ起動・migrationでは実行されない。テストデータは `created_by` の `demo-research-` 接頭辞で識別できる。

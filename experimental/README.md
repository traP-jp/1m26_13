# Experimental implementations

このディレクトリには、本体の `frontend/`、`backend/`、`api/` へ統合する前の検証実装を隔離して置きます。

- 本番環境へデプロイする対象ではありません。
- リポジトリ直下の既存アプリケーションやAPI仕様とは独立しています。
- 検証結果をもとに本体へ移植するときは、データモデル、認証、権限、API境界を改めてレビューします。

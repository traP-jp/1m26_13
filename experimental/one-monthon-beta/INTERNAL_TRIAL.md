# β版 内部試用手順

講習会を登録し、公開された教材を見つけ、完了記録がプロフィール・バッジ・ロードマップへ反映されるところまでを確認します。実名、連絡先、認証情報は入力しません。

## 準備

1. `app/`で`npm install`と`npm run check`を実行する。
2. `npm run dev`を起動し、`http://localhost:3000/`を開く。
3. PC幅と390px前後のスマートフォン幅で同じ導線を試す。

## 中心導線

1. 「登録する」から案内付き入力を開き、講習会名・概要・最初の開催を公開状態で保存する。
2. 通常フォームまたは編集画面で、班・年度・対象者・教材・前後関係を変更する。
3. 既存開催を「再放送として複製」または「次回として複製」し、複製後の値だけを変更する。元開催へ変更が戻らないことを確認する。
4. 一覧でキーワード・班・年度を指定し、登録した講習会とロードマップを見つける。0件状態から条件を解除できることも確認する。
5. 1回開催では回選択が出ないこと、複数回では`/workshops/2#3`のようなURLで該当回が開くこと、同じ回の通常開催と再放送が並ぶことを確認する。
6. 教材を確認して「受講し終わった」を押し、「学びの記録」で完了履歴と講習会バッジを確認する。
7. ロードマップを開き、完了数と「次」の講習会が同じ完了記録から更新されていることを確認する。完了取消でも逆向きに反映されることを確認する。

## 観察すること

- 画面の主操作と情報の階層が明確か。
- 単発の講習会で、不要な開催階層を意識させられないか。
- 入力エラー、読み込み中、0件、失敗、保存中、保存失敗を区別できるか。
- キーボードのTab移動とフォーカス表示で操作できるか。
- 小さい画面で横スクロールや主操作の見切れがないか。

所見は`feedback/TEMPLATE.md`を複製して記録します。Vault、Daily、traQ、wikiへ試用ログを転載・投稿しません。

# β版 自律実行計画

更新日: 2026-09-02

## β版の目的

記入済み詳細設計を正本として、既存α版の価値循環を「講習会と独立した開催」のモデルへ移行し、登録・公開・発見・詳細/教材・完了・プロフィール/バッジ・ロードマップをローカルD1の実データで一巡できるようにする。

## β版のページ一覧

- `/`: 検索バーと、公開講習会の全件カードを同じページで縦に確認するホーム。
- `/workshops`: ホームの検索結果を受け取り、キーワード・班・年度で追加絞り込みする画面。
- `/workshops?view=roadmaps`: 共通ナビから直接開くロードマップ一覧。条件検索との画面内切替は置かない。
- `/workshops/:id`: 講習会まとめ兼開催詳細。1回開催は一画面、複数回は同一画面内の回ナビゲーションと`#回番号`。
- `/roadmaps/:id`: 永続化された講習会順と、完了由来の進捗。段階名・説明は表示しない。
- `/admin/workshops/new`: 講習会名・概要を先に保存する新規作成画面。作成経路はこの画面へ統一する。
- `/admin/workshops/:id`: 講習会概要と各開催の通常編集、公開/下書き、開催複製。
- `/admin`: 講習会作成とロードマップ管理を集約する運営向けページ。
- `/admin/roadmaps/new`: 各段階の講習会と順番、booleanの公開状態を入力するロードマップ作成画面。段階名・説明は入力しない。
- `/admin/roadmaps/:id`: ロードマップの編集、公開/下書き、削除。
- `/users/demo-learner`: プロフィール、完了履歴、講習会ごとのバッジ、ロードマップ進捗。

- 静的検査・ドメインテスト: `cd app && npm run check:static`
- 隔離D1 API統合テスト: `cd app && npm run test:api`
- ビルド: `cd app && npm run build`
- migration生成（スキーマ変更時）: `cd app && npm run db:generate`
